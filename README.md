# أكاديمية التميز

منصة مغربية تفاعلية للاستعداد لمباراة ولوج سلك تأهيل أطر التدريس.

**[افتح تطبيق أكاديمية التميز](https://elkandoussi1.github.io/akademiyat-al-tamayouz/)**

## داخل التطبيق

- اختبار تشخيصي وخطة مراجعة بحسب السلك والتخصص.
- دروس، اختبارات تدريبية، دفتر أخطاء ومراجعة متباعدة.
- مكتبة مراجع وقارئ PDF وأدوات للتحضير للشفوي.
- واجهة عربية وفرنسية وإنجليزية. تظهر نصوص المواد بلغاتها الأصلية.

تعمل نسخة GitHub Pages في المتصفح وتحفظ التقدم على الجهاز. تحتاج الحسابات والمزامنة ولوحة الإدارة إلى تشغيل النسخة المستقلة بخادمها. ترتبط بنية الاختبارات بإعلان نونبر 2026، وتظهر تغطية كل تخصص في صفحته.

## ملفات المشروع

[تحميل ملفات نسخة الويب](./akademiyat-al-tamayouz-github-pages.zip). تحتوي الحزمة على ملفات HTML وCSS وJavaScript ودليل PDF والأصول اللازمة للتشغيل.

يستخرج سير عمل GitHub Actions الحزمة وينشر ملفاتها على GitHub Pages عند تحديثها على الفرع `main`.
